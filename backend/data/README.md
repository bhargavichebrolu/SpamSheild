# Getting the dataset

The dataset is not committed to this repository. See the [dataset card](../../docs/dataset-card.md) for its source, licence status and verified structure.

1. Download the dataset from [Kaggle](https://www.kaggle.com/datasets/meruvulikith/190k-spam-ham-email-dataset-for-classification). This may require a Kaggle account.
2. Extract `spam_Emails_data.csv` into `backend/data/raw/`. Do not edit this file.
3. From the repository root, run the inspection script, which checks the file's SHA-256 hash before reading it:

   ```powershell
   python backend\training\inspect_dataset.py
   ```

If the hash doesn't match, the script stops with an error and doesn't write a report. That means your file isn't the verified version. The dataset may have been updated on Kaggle, so the recorded results may not apply to your copy.

`backend/data/raw/`, `backend/data/processed/` and all `.csv` and `.zip` files are excluded from Git by [`.gitignore`](../../.gitignore).

`backend/data/processed/split_assignments.csv` is generated by `python -m training.prepare_data`, run from `backend/`. It holds only row numbers and split names, not text.
